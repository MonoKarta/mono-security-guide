# Безпека в mono: як не потрапити на банківських шахраїв

Цей репозиторій містить PDF-пам’ятку українською мовою про базові правила безпеки для клієнтів, які користуються банківськими сервісами, картками та онлайн-банкінгом.

Пам’ятка пояснює, як розпізнати поширені шахрайські схеми: дзвінки від фейкової підтримки, прохання встановити сторонній застосунок, підозрілі посилання, запити на CVV, PIN, SMS-коди та переказ коштів «для перевірки».

## PDF-файл

[Відкрити пам’ятку у PDF](./bezpeka-monobank.pdf)

## Що є в пам’ятці

- як розпізнати шахрайський дзвінок або повідомлення;
- чому не можна передавати CVV, PIN, SMS-коди та коди підтвердження;
- що робити, якщо вам пропонують встановити сторонній застосунок;
- як реагувати на прохання переказати гроші «для перевірки»;
- що зробити, якщо ви вже передали дані або спілкувалися з шахраями.

## Для кого цей матеріал

Матеріал підготовлений для користувачів, які хочуть швидко перевірити базові правила безпеки перед спілкуванням із нібито банком, службою підтримки або фінансовою організацією.

Додаткові матеріали про [Монобанк](https://www.monokarta.pp.ua/) можна знайти на інформаційному сайті monokarta.pp.ua.

## Важливо

Цей матеріал має інформаційний характер і не є офіційним документом банку. У разі підозрілої операції, втрати доступу до рахунку або підозри на шахрайство слід звертатися до офіційної підтримки банку через застосунок або офіційні канали зв’язку.
